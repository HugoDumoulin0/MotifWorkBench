# Guide d'installation Windows

## Version simple

1. Récupérer le dossier `MWB_Win` du Github
2. Ouvrir le dossier et lancer `install_and_run_windows.bat`
3. Suivre les instructions et l'application s'ouvrira pour vous.

## Alternative

1. Installer Python
2. Installer R
3. Installer Strawberry Perl
4. Récupérer le dossier `MWB_Win` du Github
5. Créer un environnement virtuel
6. Installer les dépendances (pip install -r "requirements.txt") [vous installe obligatoirement Torch CPU]
7. Lancer dans le terminal (après avoir activé votre environnement virtuel) : `python run_gui.py`
8. Vous pouvez maintenant utiliser l'outil !
