# =======================================
# Guide temporaire d'installation du projet (version Linux)
# =======================================

1. Récupérer le dossier MWB (Linux)
2. Crée un environnement virtuel dans le dossier
3. Installer les packages/dépendances du "requirements.txt" dans l'environnement virtuel
4. Vous êtes normalement prêt pour l'utilisation du programme !
