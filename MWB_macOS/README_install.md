# Guide d'installation MacOS

## Version simple

1. Récupérer le dossier `MWB_macOS` du Github
2. Ouvrir le dossier et lancer `install_and_run_macos.command`
3. Suivre les instructions et l'application s'ouvrira pour vous.
4. Pour relancer l'application après fermeture, cliquer simplement sur `install_and_run_macos.command`

## Alternative

1. Installer Python
2. Installer R
3. Perl est déjà installé sur les macOS. 
4. Récupérer le dossier `MWB_macOS` du Github
5. Créer un environnement virtuel
6. Installer les dépendances (pip install -r "src/requirements.txt") [vous installe obligatoirement Torch CPU]
7. Lancer dans le terminal (après avoir activé votre environnement virtuel) : `python run_gui.py`
8. Vous pouvez maintenant utiliser l'outil !
9. Pour relancer l'application après fermeture, cliquer simplement sur `install_and_run_macos.command`
